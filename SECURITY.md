# Безопасность

Не публикуй API-ключи и личные данные в Issues, Pull Request, скриншотах или логах.
Для сообщения об уязвимости используй приватную форму GitHub Security Advisories:

https://github.com/invoker775577-rgb/sobesych-source/security/advisories/new

Приложи версию, шаги воспроизведения и минимальный пример с вымышленными данными.
Если ключ уже стал доступен посторонним, отзови его у провайдера.

Тесты не доказывают отсутствие всех уязвимостей. Скорость реакции и сроки
исправления не гарантируются. Зависимости и внешние модели имеют свои условия
безопасности и использования.
