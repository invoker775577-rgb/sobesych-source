# Изменения Sobesych

Сделай Fork публичного репозитория и отдельную ветку под изменение.
Для исправления ошибки приложи шаги воспроизведения, ожидаемое поведение,
версию Windows и Sobesych. В Pull Request опиши изменение и выполненные проверки.

Сохраняй ручное начало и завершение звонка. Микрофон, запись, скрытый режим
и платные запросы не должны включаться при обычном открытии программы.
Отдельная Practice сохраняет собственный appId и каталог данных.

Обычные тесты работают с синтетическими данными и локальными заглушками.
Не добавляй реальные звонки, личные профили, API-ключи, содержимое `%APPDATA%`,
скриншоты чужого экрана или журналы с текстом разговоров. Платные и аппаратные
проверки требуют отдельного явного запуска и описания расходов.

Перед отправкой изменения выполни в `app/`:

```powershell
npm test
npm run lint
npm run build
```

Сообщай отдельно, что проверено unit-тестами, интерфейсом, реальными устройствами
и живой моделью. Успешная сборка не подтверждает исправление пользовательского
сценария. Для изменения аудио или очереди добавляй воспроизведение исходного сбоя.

Проверки запускаются локально командами выше. Pull Request не публикует новый
установщик автоматически. Выпуск обновления выполняется отдельно.
