# Sobesych

Приложение для звонков и подготовки к собеседованиям на Windows x64.
Распознаёт микрофон и системный звук, выдаёт AI-подсказку по кнопке и разбирает
задачу из выделенной области экрана. Для практики есть отдельное приложение.

[Скачать программу](https://github.com/invoker775577-rgb/sobesych-releases/releases/latest)
| [Открытые исходники](https://github.com/invoker775577-rgb/sobesych-source)

## Установка

1. Скачай полный `Sobesych-Setup-<версия>-x64.exe` со страницы версий и установи его.
2. Открой ярлык Sobesych. В настройках сохрани свой ключ OpenRouter.
   Создать ключ можно на https://openrouter.ai/settings/keys.
   Запросы оплачиваются с аккаунта, которому принадлежит ключ.
3. При наличии NVIDIA установи GPU-пакет через настройки программы.
4. Нажми «Начать звонок». После вопроса нажми «Что сказать?».
   Для задачи на экране используй «Выделить задачу».

В версии 0.5.81 исправлены ожидание ответа, зависание распознавания и очередь
аудио. Интерфейс от 31.10.2026 включает одну стартовую кнопку, автоматический
компактный оверлей после подключения звонка, задачи внутри звонка и переключение
скрытого режима без системного диалога. Вкладка практики убрана из основного
приложения. Готовый установщик доступен на странице версий; обновление установленной
программы выполняется через «Настройки → Проверить обновления».

## Данные и расходы

Сохранённые ключи, профили и история пользователей в исходники и установщик не
входят. Каждый пользователь вводит собственный ключ. Ключ сохраняется локально
с шифрованием средствами Windows.

По умолчанию речь распознаётся локально. Для ответа через OpenRouter программа
передаёт текст вопроса и выбранный контекст. При разборе экранной задачи
передаётся выделенное изображение. В настройках есть отдельный платный режим
транскрибации через OpenRouter; в нём аудио отправляется провайдеру.

Запись начинается по действию пользователя. При открытии программы микрофон,
запись и скрытый режим не включаются. Не записывай чужую речь и не отправляй
чувствительные данные без необходимых разрешений.

Отдельный сервер приложения не требуется. Для облачных ответов нужен интернет;
стоимость зависит от выбранной модели и объёма запросов. Ставь лимит на API-ключ
в аккаунте OpenRouter. Фиксированное число собеседований на определённую сумму
не гарантируется.

## Ограничения

- Основная поддерживаемая платформа — Windows 10/11 x64. Поддержка macOS и Linux
  не заявлена.
- Локальная большая модель без NVIDIA может сильно отставать от разговора.
  На тестовом Ryzen 5 короткие фразы занимали 25–34 секунды на CPU.
- NVIDIA-пакет загружается отдельно. Модель речи, движок и ускоритель занимают
  заметно больше места, чем исходники. Скрипты загрузки проверяют SHA-256.
- Системная защита окна от захвата может мешать записи NVIDIA и другим рекордерам.
  Для записи экрана оставь эту защиту выключенной.
- Установщик пока не подписан сертификатом Windows. Проверяй источник загрузки;
  отключать защиту Windows для установки не требуется.
- AI может ошибаться. Использование на реальном собеседовании согласуй с его
  участниками; не представляй выдуманный опыт как свой.

## Разработка

Проверено с Node.js 24. Команды выполняются в PowerShell:

```powershell
git clone https://github.com/invoker775577-rgb/sobesych-source.git
cd sobesych-source/app
npm ci
$env:SOBESYCH_DATA_DIR = Join-Path $env:LOCALAPPDATA 'Sobesych-dev'
npm run dev
```

Для проверки интерфейса достаточно запуска приложения. Чтобы начать локальное
распознавание, отдельно подготовь модель и движок:

```powershell
npm run prepare:local-stt
# Необязательно, для NVIDIA:
npm run prepare:local-stt:gpu
```

Эти команды скачивают крупные компоненты. Модель не хранится в Git.
API-ключ сохраняй в настройках программы. Для разработки также есть
`app/.env.example`; личный `.env` не коммить.

Офлайн-проверки без личного ключа, микрофона и платных API:

```powershell
npm test
npm run lint
npm run build
```

Публичный набор тестов содержит синтетические данные. Личные профили,
расшифровки, старые результаты прогонов и приватная история Git не публикуются.
Синтетическая речь проверяет аудиотракт, но не доказывает точность на любой
гарнитуре и в любом разговоре.

Отдельная проверка кнопок в скрытом Electron:

```powershell
npm run test:controls
```

Проверка настоящего распознавателя на синтезированной RU/EN-речи выполняется
после подготовки NVIDIA-компонентов и использует GPU, но не реальные устройства:

```powershell
npm run test:local-stt:regression
```

Сборка Windows-установщика:

```powershell
npm run dist:setup:win
```

Для отдельного приложения практики используй `npm run dist:practice:win`.
У него отдельные имя, appId и каталог данных.

## Своя версия

Можно сделать Fork, менять код, распространять сборки и использовать его
коммерчески с сохранением MIT-лицензии и уведомлений об авторстве.

Перед распространением своей сборки поменяй `appId`, `productName`, имя ярлыка
и настройки `publish` в `app/electron-builder.windows.yml`. Проверь также
`app/package.json` и конфигурацию отдельной Practice. Своя сборка должна
использовать свой канал обновлений и каталог данных, чтобы не подменять
официальную программу и не перезаписывать её настройки.
Имя приложения и каталог данных дополнительно заданы в
`app/electron/main.cjs`; для самостоятельного форка поменяй их тоже.

## Устройство проекта

- `app/src/` — интерфейс, аудиозахват, сегментация и выбор вопроса.
- `app/electron/` — окна, IPC, хранилище, локальный STT и обновления.
- `app/server.mjs` — запросы к провайдеру и формирование контекста.
- `app/scripts/` — подготовка зависимостей и проверки поставки.
- `app/tests/` — публичные синтетические тесты.

Инструкции для изменений находятся в [CONTRIBUTING.md](CONTRIBUTING.md),
для сообщений об уязвимостях — в [SECURITY.md](SECURITY.md).
